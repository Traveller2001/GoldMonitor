# GoldMonitor

实时黄金价格桌面悬浮窗，按交易时间在上海金交所 Au(T+D) 与国际现货金价之间自动切换。

## 功能

- 半透明圆角悬浮窗，始终置顶显示
- 实时显示人民币/克黄金参考价
- 显示当前报价来源、行情时间，以及更新失败、报价过期和休市状态
- 主界面提供刷新、设置入口；失败时保留并弱化显示最近有效报价
- 涨跌幅变色提醒（红涨绿跌）
- 同一市场的较昨收涨跌幅显示；国际源缺少昨收基准时显示 `--`
- 今日最高/最低价显示
- 可配置区间时长，对比区间内价格变化
- 独立趋势图区，按所选时长展示同一数据源的走势，断档不连线
- 支持设置刷新间隔、变色阈值
- 价格突破阈值时发送系统通知
- 通知异步发送，失败后允许重试，不阻塞拖拽和刷新
- 最近日志查看器（自动保留近 1 小时记录）
- 毛玻璃风格设置面板与日志面板
- 系统托盘图标，支持显示/隐藏
- 鼠标拖拽移动窗口位置，靠近屏幕边缘自动吸附收边
- 区间涨跌配色随波动幅度增强，剧烈波动时背景/边框/曲线联动变色
- 跨平台支持（macOS / Windows / Linux）

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```

## 使用方法

- **拖拽移动**：左键按住窗口拖动，靠近边缘松开可自动贴边收起
- **贴边展开**：鼠标移到边缘露出的细条上，悬浮窗会自动滑出
- **右键菜单**：设置 / 最近日志 / 刷新 / 退出
- **快捷入口**：窗口右上角可直接刷新行情或打开设置
- **系统托盘**：右键可显示/隐藏窗口、打开设置、查看日志

## 设置项

| 设置 | 默认值 | 说明 |
|------|--------|------|
| 刷新间隔 | 30 秒 | 价格更新频率 |
| 变色阈值 | 0.5% | 区间涨跌达到此值后开始增强配色 |
| 区间时长 | 5 分钟 | 对比该时段内的价格变化 |
| 高价通知 | 0（关闭） | 金价 ≥ 此值时发送通知 |
| 低价通知 | 0（关闭） | 金价 ≤ 此值时发送通知 |

## 数据来源

- 招商银行黄金行情 API（上海金交所 Au(T+D)）：北京时间周一至周五 9:00-11:30、13:30-15:30、19:50-次日 2:30；周五夜盘延续至周六 2:30。
- Swissquote XAU/USD 与 USD/CNH：瑞士时间周一至周五 00:05-22:55，程序通过 `Europe/Zurich` 时区自动处理夏令时。

程序只使用当前处于交易时段且接口时间戳仍新鲜的报价。Au(T+D) 时段优先使用招行，休市后自动使用国际源；节假日或接口异常时按报价有效性回退，面板不显示数据源切换控件。

国际源通过 XAU/USD 与 USD/CNH 换算参考价，不使用 Au(T+D) 的昨收价计算日涨跌。报价时间取黄金与汇率中较旧的一项。两种来源的历史分别保存，避免切换时产生虚假区间涨跌。

走势图和区间涨跌使用本次运行以来积累的有效报价。支持最长 120 分钟观察窗口；启动后历史不足时显示“积累中”。休市或更新失败时保留最后报价并标明状态；超过 180 秒的报价标记为过期。

## 维护与验证

```bash
QT_QPA_PLATFORM=offscreen python3 -m unittest discover -v
```

Windows PowerShell 可先执行 `$env:QT_QPA_PLATFORM="offscreen"`，再运行 `python -m unittest discover -v`。

测试覆盖行情时间与数据校验、来源切换、历史保留、界面状态、线程退出、通知超时、配置和日志损坏恢复，不请求真实行情或发送系统通知。

- `api.py`：行情获取、交易时间、报价校验与备用源处理。
- `main.py` / `chart.py`：悬浮窗交互、状态呈现和趋势绘制。
- `price_history.py`：按来源隔离的历史数据与区间计算。
- `notifications.py`：带超时的异步系统通知。
- `settings.py` / `logs.py`：配置原子保存、日志追加与定期清理。
